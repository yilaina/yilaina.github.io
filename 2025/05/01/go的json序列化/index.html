golang的json序列化问题

序列化是什么？

序列化（Serialization） 是将数据结构或对象状态转换为一种特定格式的过程，以便于存储（如保存到文件）或传输（如通过网络发送）。序列化后的数据可以在需要时通过 反序列化（Deserialization） 恢复为原始数据结构或对象。

在我们进行前后端数据交换时，我们一般用的都是json格式进行数据交换。在这个过程中，我们需要使用预定义好的数据结构对不同于自己的数据格式进行接收，对于后端来讲的话，如go的话，一般情况是通过提前定义一个结构体，并通过json标签来指定解析后的数据的名称是什么，以及反序列化后的名称是什么，通过这样的映射关系就搭起了两个不同语言之间互相进行数据交流的桥梁。

接下来我们来一点一点的深入了解序列化和反序列化。

1、什么是结构体标签

在 Go 语言中，结构体标签（Struct Tags） 是附加在结构体字段声明后的元数据，用于为字段提供额外的信息（如序列化规则、ORM 映射关系等）。它们通过反引号`包裹的字符串定义，语法简洁但功能强大。

性能开销：反射操作会带来一定性能损耗，高频场景建议使用代码生成工具（如 easyjson）。

4、解决go传递数据失真问题

在Go后端通过雪花算法生成的 int64 随机数字（如 9223372036854775807）传递到前端时，由于JSON中的数字类型（基于JavaScript的 Number 类型）只能安全表示 2^53 -1（即 9007199254740991），超出部分可能会导致精度丢失。为了解决这个问题，可以通过 JSON 结构体标签 将 int64 字段序列化为字符串，从而避免精度问题。
