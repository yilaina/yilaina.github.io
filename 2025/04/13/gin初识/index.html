前言

本篇文章适合没有任何go语言基础未来想进行web开发的初次学习，希望能让你也感受到用go语言原生http库以及gin框架进行web开发的高效和灵活亦或者是为未来从事后端开发打下基础。话不多说，让我们开始吧。

首先我们要知道我们在浏览器中点开搜索框，然后输入网页地址后跳转到页面这中间的大致过程。

在url地址栏中输入如www.baidu.com后，页面跳转到了

在这过程中，发生了什么？简单来说的话就是一次请求和一次响应。在我们在地址栏输入地址按下回车后，本机电脑向服务器发送了一次请求，如果一切顺利的话，本机电脑会收到一个来自服务器的响应。

简单的了解了一下web的基础知识后，让我们开始用go语言进行web应用的开发吧！！

3、模板的引入

1、模板初识

在一些前后端不分离的Web架构中，我们通常需要在后端将一些数据渲染到HTML文档中，从而实现动态的网页（网页的布局和样式大致一样，但展示的内容并不一样）效果。
模版可以理解为事先定义好的html文件，模板渲染简单理解就是指一些数据可以通过文本替换方式来替换文本中预定义标记的数据。

1、模板与渲染的关系

在开发中，模板（Template）就是预先设计好的 HTML 结构，它定义了页面的布局和内容展示方式。比如，页面的头部、尾部、导航栏、内容区域等，都是通过模板来规划的。
在开发中，渲染（Rendering）就是将动态数据填充到模板中，生成最终的 HTML 页面。模板是固定的结构，但数据是动态的。比如，同一个新闻列表模板，可以根据不同的数据渲染出不同的新闻内容。
模板是结构：它定义了页面的框架和布局。
渲染是过程：它将动态数据填充到模板中，生成最终的页面。

2、为什么需要模板和渲染？

效率：避免重复造轮子
一致性：保证输出结果符合规范
灵活性：同一模板能适应不同场景（如电商页面用同一模板展示不同商品）

3、模板和渲染总结

模板和渲染的关系就像“模具”和“填充”的关系：
模板是固定的结构，决定了页面的布局。
渲染是动态的过程，将数据填充到模板中，生成最终的页面。

通过模板和渲染的结合，开发者可以高效地创建动态、美观的网页，就像用模具快速制作出不同口味的蛋糕一样。

2、模板引擎

###1. 模板引擎的核心功能
模板定义：允许你编写一个固定结构的模板（如HTML页面），其中包含一些占位符（如 {{ .name }}）。
数据绑定：将动态数据（如用户信息、商品列表）注入到模板的占位符中。
逻辑控制：支持简单的逻辑操作，比如条件判断、循环遍历等。
输出生成：将模板和数据结合，生成最终的文本（如HTML、XML、JSON等）

3、 模板引擎的优点

分离逻辑与表现：开发者可以专注于业务逻辑，设计师可以专注于页面设计。
提高开发效率：避免重复编写相似的代码，支持动态生成内容。
易于维护：修改模板时，无需改动业务逻辑代码。

4、模板引擎总结

模板引擎 是一种工具，它的作用是将数据动态插入到预定义的模板中，生成最终的文本输出。简单来说，它就是 模板 + 数据 = 输出 的桥梁。

2、go语言中的模板引擎

很多编程语言的web框架都使用了各种模板引擎，比如python中flask框架的jinja2模版引擎。
Go语言内置了文本模板引擎text/template和用于HTML文档的html/template。
template 包（html/template）实现了数据驱动的模板，用于生成安全的 HTML 输出，防止代码注入。它提供与text/template相同的接口，因此当输出为 HTML 时， 应使用它来代替 text/template 。
